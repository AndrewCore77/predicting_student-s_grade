# 🎓 Student Grade Prediction

Проект по машинному обучению для прогнозирования итоговой оценки студента (`G3`) на основе учебных и личных характеристик.

## Структура 

README.md - указания; 
student-mat.csv - датасет; 
student_grade_prediction.ipynb - сам проект

## Обзор проекта

В этом проекте анализируется успеваемость студентов и строится модель **линейной регрессии** для предсказания финальной оценки.
В датасете используются такие признаки, как:

- время на учебу
- предыдущие оценки (`G1`, `G2`)
- количество пропусков
- семейные и социальные факторы

## Этапы работы

1. Загрузка данных
2. Разведочный анализ данных (EDA)
3. Отбор признаков
4. Предобработка данных
5. Обучение модели (Linear Regression)
6. Оценка качества модели

## Стек

- Python
- pandas
- numpy
- seaborn
- matplotlib
- scikit-learn
- Jupyter Notebook

## Ключевые выводы

- Предыдущие оценки (`G1`, `G2`) сильнее всего влияют на итоговую оценку (`G3`)
- Время на учебу положительно связано с результатами
- Пропуски занятий ухудшают итоговую успеваемость
